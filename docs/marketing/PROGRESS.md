# 키위 홍보 진행 상황

마지막 갱신: 2026-09-15

SNS 계정 준비·콘텐츠 제작·게시·성과는 이 문서에서 관리합니다.
개발 및 서비스 운영 기록은 [개발 진행 상황](../PROGRESS.md)을 참고하세요.

## 1. 현재 상태

**첫 2주 분량의 홍보 자료 준비 완료. 계정 개설과 실제 게시는 아직 하지 않았습니다.**

- 대상 채널: 네이버 블로그, Threads, 인스타그램
- 말투: **친근한 존댓말 — 쉽게 설명하는 트렌드 가이드** (사용자 선택)
- 초기 독자 제안: 글감이 필요한 블로거·콘텐츠 제작자
- 공통 메시지 초안: **지금 뜨는 검색어, 흐름까지 읽다.**
- 서비스: https://keywi.kr

## 2. 완료한 작업

### 2026-09-15 — 첫 홍보 패키지 제작

- 채널별 계정 이름·아이디 후보·소개 문구 작성
- 네이버 블로그 원고 3편, Threads 원고 6편 작성
- 인스타그램 게시물 원고 3편과 게시용 이미지 3장 제작
- 기존 공식 심볼 PNG를 프로필 사진으로 준비
- 첫 2주 게시 일정, 해시태그, 스토리 및 댓글 답변 문구 작성
- 채널 구분용 UTM 링크 준비 (실제 유입 집계 동작은 미확인)
- 자료 6개 파일을 `eba9903`으로 커밋하고 `origin/dev`에 푸시 완료

### 자료 위치와 용도

| 자료 | 용도 |
| --- | --- |
| [전체 원고·게시 일정](launch/launch-kit.md) | 계정 소개, 채널별 원고, 운영 메모 |
| [프로필 사진](launch/profile.png) | 세 채널에 공통으로 사용할 기존 키위 심볼, 180×180 PNG |
| [게시 이미지 1](launch/instagram-01.png) | 첫 게시물: 키위 서비스 소개 |
| [게시 이미지 2](launch/instagram-02.png) | 두 번째 게시물: 검색 관심도 100의 의미 |

**큰 글자가 들어간 이미지 3장은 순서대로 게시할 콘텐츠입니다. 프로필 사진 후보 3종이 아닙니다.**
프로필 사진은 `profile.png` 한 장으로 별도 준비했습니다.
인스타그램 후속 게시물을 여러 장 카드로 확장하는 문구도 원고에 있지만, 해당 확장 이미지들은 아직 제작하지 않았습니다.

## 5. 운영 기준

- 서비스 표기는 **키위 / Keywi**로 통일합니다.
- 순위 출처는 Google 트렌드, 검색 관심도 추이는 네이버 데이터랩입니다.
- 운영자가 작성한 콘텐츠임을 밝히고 사용자 후기처럼 꾸미지 않습니다.
- 실제 순위·리포트를 게시할 때는 데이터 확인 후 날짜·시각(KST)·출처를 표시합니다.
- 게시 전 제작 완료와 실제 게시 완료를 구분합니다.
- 첫 2주 후 각 채널에서 확인 가능한 조회·저장·댓글·프로필 방문·링크 클릭을 기록합니다. 현재 성과 측정값은 없습니다.
- 원고나 이미지를 수정하면 배포용 ZIP도 함께 갱신합니다. 이 진행 문서는 ZIP 밖에서 관리합니다.
