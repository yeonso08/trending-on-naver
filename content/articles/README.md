# 글 쓰는 법

이 폴더의 `.md` 파일 하나가 글 하나입니다. `README.md`와 `_`로 시작하는 파일은 글로 취급하지 않습니다.

## 1. 파일 만들기

파일 이름이 주소가 됩니다. **영문 소문자·숫자·하이픈만** 씁니다.

```
content/articles/datalab-ratio-guide.md  →  https://keywi.kr/articles/datalab-ratio-guide
```

한글 파일 이름이나 공백이 있으면 빌드가 멈추고 어느 파일이 문제인지 알려 줍니다.

## 2. 맨 위에 정보 적기

```markdown
---
title: 네이버 데이터랩 '검색 관심도 100'은 무슨 뜻일까
description: 데이터랩 수치는 검색 횟수가 아니라 상대값입니다. 기간을 바꾸면 숫자가 달라지는 이유와 흔한 오해를 정리했습니다.
date: 2026-09-15
# updated: 2026-09-20   내용을 크게 고쳤을 때만
# author: 홍길동        비우면 "키위"
# draft: true           초안. pnpm dev에서만 보이고 배포되지 않음
---

본문은 여기부터 마크다운으로 씁니다.
```

- `title`, `description`, `date`는 필수입니다. 빠지면 빌드가 멈춥니다.
- `description`은 글 목록과 검색 결과에 나오는 한두 문장입니다.

## 3. 본문 쓰기

- 소제목은 `##`, 그 아래는 `###`. 제목(`#`)은 위의 `title`이 대신하므로 본문에 쓰지 않습니다.
- 표, 인용(`>`), 목록, 굵게, 링크, 코드 모두 됩니다.
- 사이트 안 링크는 경로만: `[오늘의 검색어 기록](/daily/2026-09-15)`
- 외부 링크는 자동으로 새 탭에서 열립니다.
- 범위를 나타내는 물결표는 숫자 사이든 글자 사이든 `1\~2분`, `10월 중순\~11월 초`처럼 앞에 `\`를 붙입니다. 한 줄에 `~`가 두 개 있으면 Prettier가 취소선(`~~`)으로 바꿔 사이 글자에 줄이 그어집니다. `title`·`description`에는 붙이지 않습니다(평문으로 그대로 보임).

### 이미지

`public/images/articles/<파일 이름>/`에 넣고 이렇게 씁니다.

```markdown
![트렌드 분석 화면에서 기간을 1년으로 바꾼 모습](/images/articles/datalab-ratio-guide/yearly.png)
```

대괄호 안 설명(대체 텍스트)은 비우지 마세요.

## 4. 확인하고 올리기

```bash
pnpm dev        # http://localhost:3000/articles 에서 확인 (초안도 보임)
pnpm build      # 형식 오류가 있으면 여기서 멈춤
```

- 키위 화면 캡처와 직접 뽑은 수치를 넣으세요. 다른 곳에 없는 근거가 됩니다.
- 날짜별 기록(`/daily/...`)이나 검색어 상세(`/keyword/...`)로 링크를 거세요.
- 첫 글이 올라가면 헤더에 '인사이트' 메뉴와 사이트맵 항목이 자동으로 생깁니다.
